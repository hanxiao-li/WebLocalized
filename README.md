# 游戏本地化公司官网

本地可运行的官网和管理后台，使用 React、Express 和 SQLite。公司名称、项目及图片目前为演示内容，请在后台替换真实资料。

## 本地启动

需要 Node.js 24（本项目在 24.14.1 验证）。第一次使用执行 `npm install`，之后双击 `start-local.cmd`，或执行：

```powershell
npm run build
npm start
```

官网：http://localhost:3000/；后台：http://localhost:3000/admin。

首次打开后台，用 `data/setup-token.txt` 中的一次性口令创建自己的超级管理员。密码至少 12 位。初始化后口令文件自动移除。没有默认正式管理员密码。

开发模式执行 `npm run dev`。3001 端口为开发过程中使用的独立测试站，其账号及内容与正式本地站不同，请使用 3000 进行日常编辑。

## 编辑和发布

- “网站内容”：修改公司名称、首页标题、主图、服务、流程、联系与隐私说明。中文页新增“公司 Logo 与浏览器图标”，上传透明 PNG / WebP 后保存并发布，所有语言共享该 Logo；移除后恢复默认公司图标。导航固定置顶。
- “文章管理”：中文撰写，支持 Markdown；保存草稿后预览，确认后发布。
- “项目案例”：首页为 3D 层叠轮播，封面标题位于左下；当前案例的视频显示在旁边，手机端在下方。支持箭头、键盘方向键及横向滑动。支持 MP4（建议 H.264）/ WebM，最大 80MB，不配置就不显示播放器。
- 案例详情包含项目故事、项目信息、需求/方案/成果、可选成果数据，以及图片、图文、文字、视频分区。可添加、排序和移除分区。后台“预览草稿”可检查布局。
- 已将用户提供的 `public/assets/videoplay.mp4` 配置到第一个演示案例的三个语言版本，首页视频进入可视区域后静音播放，切换案例或离开可视区域暂停；详情页有视频时替代首屏图片，滚动继续播放，离开页面停止。原生控制条可暂停或开启声音，减少动态效果模式不自动播放。可在后台移除或上传替换；第二个案例仍保持无视频，用于展示可选布局。
- 官网文字到屏幕约 78% 高度时逐块出现，持续 1.6 秒；首页标题持续 1.8 秒，每页只播放一次。系统启用“减少动态效果”时直接显示内容；后台编辑界面不使用滚动入场。
- 所有语言独立保存、发布、下架；保存不会自动修改已发布页面。
- “语言管理”：中文、英文、日文已准备演示内容。新语言先创建译文、发布网站内容，再启用。访客首次按浏览器语言匹配，无匹配默认英文；手动选择会被记住。超级管理员可调整兜底语言。
- “系统设置”：配置兼容 Chat Completions 的 HTTPS API 地址（通常以 `/v1` 结尾）、模型和密钥。AI 生成按钮将已保存中文发送给该服务，只保存译文草稿。需自行审校后发布。密钥仅保存在本地加密数据库配置中，不返给前端。真实外部 AI 调用尚未验证，测试使用模拟服务验证流程。
- “管理员”：超级管理员可配置账号及角色；管理员管理内容/发布/统计/咨询，编辑员编辑草稿，分析员查看统计。
- “访问统计”：按日查看 PV/UV、国家或地区、网站语言、浏览器语言，并可筛选和导出。地区基于 IP 估算，本机访问显示未知；UV 依赖浏览器 Cookie，仅为估算。
- “客户咨询”：查看官网表单提交的需求。当前保存到后台，不自动发送邮件。

## 数据与备份

内容、账号、访问记录及上传文件全部位于 `data`，不会上传到其他托管平台。只有点击 AI 生成时，待翻译内容才会发到配置的 AI 服务。

备份时先停止网站，再完整复制 `data` 文件夹（含 `studio.sqlite`、可能存在的 WAL 文件、`secret.key`、`uploads`）；恢复时保持整套数据一致。务必保留 `secret.key`，否则已保存 AI 密钥无法解密。不要把 `data` 或 `.env` 放进公开仓库。

## 日后部署到服务器

当前只监听本机。准备上线时，在服务器安装 Node.js 24，复制源码并安装依赖、构建，迁移完整 `data`。从 `.env.example` 创建 `.env`，设置实际 HTTPS `APP_ORIGIN`、`COOKIE_SECURE=true`。使用同机 Nginx / Caddy 反向代理时，可设置 `TRUST_PROXY=loopback`，让统计读取真实访客 IP；不要盲目信任所有代理头。

由反向代理配置 HTTPS、域名、上传大小和进程守护。单实例 SQLite 适合初期站点；多实例扩容需迁移数据库和上传存储。当前是前端路由页面，全面搜索引擎优化/服务端渲染尚未实现。上线前替换演示内容并验证真实 AI 服务、视频素材及服务器地区识别。尚未执行线上部署。
